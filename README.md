# soccerIsland

アニメ調2Dのサッカー・オープンワールド。島民全員が小さい頃からサッカーをしている島に、大人の主人公が引っ越してくる。

### 使い方

1. 空の GameObject に `NPCManager` を付ける（`config` は空ならデフォルト設定）。
2. 調整したい場合は Project ビューで **Create > SoccerIsland > NPC Generation Config** を作り、`NPCManager.config` に設定。
3. ゲームからの呼び出し:

```csharp
var mgr = NPCManager.Instance;
ConversationResult r = mgr.Talk(npcId);          // 会話：r.lines にセリフ、r.marketChanges に価値変動
NPCProfileView p = mgr.GetProfile(npcId);        // 判明済みの情報だけ入ったプロフィール
var top = mgr.Database.GetOfficialMarketValueRanking(20); // サッカー協会の市場価値ランキング
var tel = mgr.Database.FindByPhone("島-1234-5678");       // 電話システム
mgr.AdvanceDay();                                 // 1日進める（365日で年越し）
mgr.Save();
```

4. エディタで **SoccerIsland > NPC Database Viewer** を開くと、シードを変えて島を生成し、1000人の中身（隠し能力・潜在・覚醒年齢・人生周回）を確認できる。

## 実装済み：会話とワールドの連動（`Assets/Scripts/World`）

NPCの話題は必ずワールドの実データから作るので、**話したことは実際に起きている**。

- **試合の話をしたNPCは、その試合に必ず出場する**（出場メンバーは予定作成時に確定）
- **買ったと言った商品は、必ず完売か商談中**（再入荷で状態が変わった話はしない）
- 裏フットサル・裏市場の話は好感度60以上でないとしない

| 曜日 | 試合 |
|---|---|
| 水 | 刑務所リーグ（A棟 vs B棟） |
| 金・深夜 | 裏フットサル（会場は廃墟・倉庫などで毎回変わる） |
| 土 | 職場対抗戦、ビーチサッカー |
| 日 | 草サッカー（4週に1回は地域対抗試合） |
| 60日ごと | 島代表戦 |

お店：サッカーハイボール、魔除けタバコ、ノイローゼ注射、若返りフレーク、使用済みポテチ、脅迫タピオカ（表では常に完売・裏市場にだけ在庫）、限定スパイク（商談制）など。高額品は商談中→成立/破談。

使い方：`NPCManager` と同じシーンに `WorldManager` を置く。日付は `NPCManager.AdvanceDay()` で進める（その日の試合・買い物は WorldManager が処理）。

```csharp
var world = WorldManager.Instance.World;
var today = world.TodaysMatches();                 // 今日の試合（観戦・参加用）
var item  = world.State.GetItem(id).SurfaceStatus; // 表のお店で見た状態
```

## 実装済み：スカウト・お金・知名度・新聞（`Assets/Scripts/Career`）

**スカウト** — 獲得には市場価値を払う（エゴイスト1.2倍・献身的0.9倍・ゴッド1.5倍・協会未登録1.5倍）。
話したことがない／好感度不足／服役中／15歳未満は獲得できない。裏の人間は「裏の顔」を教えてもらい裏市場に入れないと獲得できない。
給料は30日ごと（年俸の1/12）。2か月払えないと退団して元のクラブに戻る。

**銀行** — 預金（利息あり）、借入（信用スコアと主人公の市場価値で枠が決まる。年利3〜15%）。延滞すると信用が落ちて借りられなくなる。
**闇金**（裏市場） — トイチ（10日で1割）。延滞すると 嫌がらせ → **八百長の要求** → 差し押さえ。`ForgiveHalfForFix` で八百長イベントと連動。
**株** — チーム株（試合結果・所属選手の話題性）と商店株（売れ行き・完売）。
**toto / 裏toto** — オッズは「表で見えている実力」から計算。裏で本気を出す選手を知っていれば裏totoで勝てる。刑務所リーグは対象外。
**宝くじ** — 1枚300円、毎週日曜抽選。6桁一致1億円〜下1桁300円。

**知名度** — 試合の活躍（地域対抗2倍・島代表3倍、裏の試合はほぼ0）、ゴールパフォーマンス（派手さ×新鮮さ）、ファン対応で上下。試合に出ないと忘れられる。主人公の市場価値は知名度で決まる。
**ファン** — 有名になると島民がサイン・写真・握手を求めてくる（性格・年齢で頻度が違う）。サインは自作が必要。断ると「塩対応」記事になることも。
**自作サイン** — 0〜1座標の線データ（`SignatureDesign`）。`SignatureTexture.Render` で Texture2D に描ける。
**ゴールパフォーマンス** — 15種類の動きを最大6個組み合わせる。ユニフォーム脱ぎはイエロー、挑発系はゴシップになる。

**サッカー新聞（毎朝）** — 試合結果、移籍、市場価値の急変、覚醒・出所、お店の完売、株の急騰、宝くじ当選番号、主人公の話題、有名人のゴシップ（不仲説・密会など。載った人の市場価値が動く）、毎週の協会ランキング、毎月の人気投票。裏フットサル・刑務所リーグは表の新聞に載らない。

使い方：`NPCManager`・`WorldManager` と同じシーンに `CareerManager` を置く。

```csharp
var career = CareerManager.Instance.Career;
var r = career.Interact(npcId);                       // 会話＋ファンのお願い（r.fanRequest）
career.Scouting.Scout(npcId);                         // ScoutResult が返る
career.Bank.Borrow(Lender.Bank, 5000000, 180);
career.Betting.PlaceBet(matchId, TotoPick.Home, 10000);
career.Fame.RecordMatch(MatchCategory.Kusa, 8.0f, goals: 1, assists: 1, beautifulSkills: 2);
CareerManager.Instance.OnNewspaper += issue => ShowPaper(issue);
```

## 実装済み：試合（キャプテン翼式のコマンドRPG）・チームの雰囲気（`Assets/Scripts/Match`）

試合はファミコンのサッカーRPGと同じく、**自チームのボール保持者・守備者・キーパー全員にコマンドを出す**方式（`ControlMode.FullTeam`、既定）。
フィールドは攻撃方向7ゾーン×左右中央の3列。ボールを持って進むと相手と「対決」になり、コマンドを選ぶ。
**ガッツ**を消費して行動し、少なくなると力が出ない。能力値・テンション・ガッツ・チームの雰囲気・運で勝敗が決まる。
シュート・セーブ・必殺技・ゴールなどの場面は `MatchEvent.cutIn` が立ち、2Dアニメ調のカットイン演出（顔アップ＋技名＋叫び）を入れられる。
技名・キャラはすべてオリジナル（島にちなんだ名前）。

| 場面 | コマンド |
|---|---|
| 攻撃 | ドリブル / 華麗なドリブル / 必殺ドリブル / パス / ロングパス / ワンツー / センタリング / シュート / 必殺シュート / キープ / バックパス |
| 守備 | タックル / 必殺タックル / パスカット / ブロック / 必殺ブロック / オフサイドトラップ / 様子を見る |
| キーパー | キャッチ / パンチング（こぼれ球あり） / 必殺セーブ |
| 空中戦（味方のセンタリング） | ヘディング / ボレー / トラップ |
| 空中戦（相手のセンタリング） | クリア / 競る / パスカット |
| 八百長中のみ（主人公） | わざと外す / わざとパスミス |

**必殺技**：島民は能力・性格から必殺技を持つ（シュートが得意なら必殺シュート、GKなら必殺セーブ…）。主人公はレベルで覚える（Lv3「移住者シュート」、Lv5「潮風ドリブル」、Lv8、Lv12、Lv16…）。
**レベル・経験値**：試合での成功プレーと勝敗で主人公に経験値。レベルが上がると能力値・ガッツが伸びる（`PlayerGrowth`）。
**指示を聞かない選手**：味方に出したコマンドは性格で無視されることがある。エゴイストはパスを命じても「うるせえ、俺が行く！」、センス的は地味な指示を嫌い、ヒステリーはカッとなって突っ込む。献身的は必ず従う。チームメイトの評価が低いと誰でも聞かなくなる。

**チームメイトの評価（信頼）**：ドリブル突破すると下がる → そこからチャンスを作ると一気に上がる。キープ・バックパス・様子見など消極的だと一気に下がる。
評価が高いほどボールが回ってきて、指示も聞いてもらえる。

**性格バランス**（`TeamChemistry`）：内向的・外交的・根暗の偏り、エゴイストの人数、献身的がエースを支えているか、センス的に支え役がいるか、ヒステリー・ファイターの多さ、ムードメーカーの人数で雰囲気が決まる。ムードメーカーのテンションは試合中のチームの雰囲気を引っ張る。

**ミーティング**（`Meeting`）：攻撃的に／守備から／楽しもう／気合／エースに任せる／チームのために／自由に／オフサイドトラップ／ボーナス。性格で受け取り方が違い、方針をめぐって口論になる（ムードメーカーがいると収まることも）。

**コーチング**（`Coaching`）：性格ごとに試合中の要求が出る（エゴイスト「こっちによこせ」、ムードメーカー「褒めて」、ヒステリーはイライラ→落ち着かせる、ファイター「体ぶつけていいか」、献身的「指示をくれ」、センス的「自由にやらせて」）。応えるとテンション・評価が上がる。ヒステリーを叱ると爆発、内向的な人を叱ると萎縮。

**試合イベント**（`MatchMissions`）：足がつった状態で指示だけで勝利 / ファンが見てる、綺麗な足技で活躍しろ / ベテランとしてオフサイドトラップを5回 / 八百長をしろ、わざと負けろ（露骨だと観客にばれる。闇金の借金と連動）

使い方：
```csharp
var session = MatchSession.ForTodaysTeamMatch(career, new CrampMission(20));
session.HoldMeeting(MeetingTopic.Enjoy);
var prompt = session.Advance();             // 主人公の出番まで進む
session.Choose(MatchCommand.Dribble);
session.Coach(CoachingCommand.Praise, prompt.actor); // いつでも（クールダウンあり）
session.AutoPlay();                          // 残りおまかせ → 結果は島に反映
```
確認用に `MatchDebugView`（OnGUI）をシーンに置くと、エディタ上で試合を遊べる。

## 実装済み：フォーメーション・作戦

5つの陣形（4-4-2 / 4-3-3 / 3-5-2 / 5-4-1 / 3-4-3）と7つの作戦（バランス・カウンター・サイド攻撃・中央突破・パスをつなぐ・前線からプレス・ゴール前を固める）。

## 実装済み：練習・能力検定

**能力検定**：主人公が協会で受けられる（初段・1級〜10級）。級が上がると知名度が上がる。**島民の級は公開しない**（相手の実力の手がかりは市場価値だけ）。
**練習**：1日3回まで。能力が上がるが疲労がたまり、試合でガッツが減る。仲の良い島民と練習すると伸びが良く、好感度も上がる（相手の実力はわからない）。

## 実装済み：電話

番号を知っている島民に直接かけられる（1人1日1回）。出てくれるかは性格・好感度次第。
用件：話す（会話と同じ）／練習に誘う／ほかの人について聞く（相関図が増える）。
仲良くなった島民からはかかってくる：試合の助っ人の誘い（`MatchFactory.FromInvite` でそのまま試合へ）・噂話・お礼。闇金の取り立ての電話も来る。
番号はすべて島内専用の架空の番号で、端末の電話機能・連絡先は使わない。

## 実装済み：周回プレイ（転生）・恋愛（`Assets/Scripts/Career/Reincarnation`）

- **引退と転生**：30歳から引退できる（45歳で強制引退）。引退すると前世の記録（能力・レベル・チームの最後の姿・知り合った化ける選手）が残り、**同じ島で次の人生が始まる**。スタートの街は変わる。本人は気づいていない。
- **既視感**：前世で知った「化ける選手」は、初めて会うのに名前と「いつか化ける」ことを知っている。
- **ラスボス**：2周目から「島の頂上決戦」が開催され、決勝で**仮面のチーム**と当たる。正体は前世の主人公とそのチームだが、名前はすべて伏せられる（主人公と同じ技を使ってくる……）。
- **3周目**：「転生の謎を解く最終決戦」で、転生を繰り返させている**島主**と対決。
- **恋愛（2周目から）**：相手は20歳以上の島民（性別は問わない）。デート（性格で好きな場所が違う）・プレゼント（お店の商品を買う。一点物なら完売）・告白。恋人と同じチームだと試合で燃える。有名だと熱愛がゴシップになる。

## 実装済み：島のイベント（`Assets/Scripts/Career/Island`）

- **裏市場**：場所は3日ごとに変わる（深夜のバー、廃墟、港の倉庫…）。裏の顔を持つバーテンダー・店員・マフィアと仲良くなると今の場所を教えてくれる。中では裏ルートの商品、**裏ランキング**、裏でしか出回らない人の情報（情報屋）が買える。
- **謎のプレーヤーを探す**：島民の噂から手がかりを3つ集める（夜のグラウンド → どの街 → 昼間の職業）と目星がつき、本人に話しかけると正体がわかる。わかると「裏の王者」の弱点になり、勝てるようになる。
- **漂流者**：島から出られない人たち。協会に登録してあげる（100万円）と試合に出られるようになり、恩を感じてスカウトは半額。

### 個人情報の方針

- 端末（スマホ）内の個人情報は使わない：連絡先・電話番号・位置情報・カメラ・マイク・端末ID・端末名・広告ID・クリップボードを読まない。
- 外部に出さない：通信・アナリティクス・外部URLを開く処理を持たない。セーブは端末内のみで、iOSではiCloudバックアップ対象外にする。
- NPCの名前・電話番号はすべて架空。電話番号は実在番号と一致しない `島-XXXX-XXXX` 形式。
- `PrivacyComplianceTests` が、`Assets/Scripts` に上記に反するAPIが入ると失敗する。
- エディタ起動時に Analytics / Performance Reporting / Crash Reporting を自動でオフにする（`Assets/Scripts/Privacy/Editor`）。
- Android ビルド時に `allowBackup=false` を自動で書き込み、Google のクラウドバックアップに含めない。

### テスト

Unity の Test Runner（EditMode）で `SoccerIsland.NPC.Tests` を実行。
